# MOHAMED FAREED ARENA

واجهة أولية لموقع دوري مدرسة محمد فريد، جاهزة للتطوير والرفع على GitHub.

## الموجود حاليًا
- واجهة عربية RTL ومتجاوبة للموبايل والكمبيوتر.
- هوية مؤقتة كحلي وذهبي.
- أقسام المباريات والترتيب والمتصدرين.
- صفحة مبدئية للوحة الإدارة.
- ملف SQL لإنشاء الجداول الأساسية وسياسات RLS.

## قبل تفعيل الإدارة
صفحة `admin.html` ليست تسجيل دخول حقيقيًا بعد. لا تضف كلمات مرور داخل ملفات الموقع.
بعد إنشاء مشروع Supabase:
1. شغّل `sql/schema.sql` في SQL Editor.
2. أنشئ حساب المشرف الوحيد من Authentication.
3. أضف UUID الخاص بحسابك إلى `public.admin_users` من SQL Editor.
4. اربط الواجهة بمفتاح Supabase anon/publishable فقط.
5. اختبر أن الزائر يستطيع القراءة ولا يستطيع الكتابة، وأن حساب المشرف وحده يستطيع الإدارة.

**ممنوع تمامًا وضع `service_role` key في GitHub أو في كود المتصفح.**

## بيانات البطولة
المشروع يبدأ بدون أسماء فرق أو لاعبين أو نتائج وهمية. أضف البيانات الحقيقية عند استلامها.
